## Omarchy Kirby Theme
<img width="2560" height="1440" alt="image" src="https://github.com/user-attachments/assets/4de957b5-8fd5-4fda-91ce-69b0cde18548" />


Installation
```
omarchy-theme-install https://github.com/dsnsgithub/omarchy-kirby-theme
```

If the Menu Bar is not transparent,
toggle Transparency under Omarchy Menu, Style > Menu Bar > Transparency.

Right click the time in the Menu Bar until it matches the one shown in the picture or the one you prefer.
